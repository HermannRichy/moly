# MOLY

Rappels quotidiens de grammaire, de conjugaison et d'orthographe, et expressions pour un français soutenu.

## Structure

- `apps/mobile` : application Expo (Expo Router, TypeScript), compatible Expo Go.

## Commandes

```bash
pnpm install        # à la première installation, ou quand une dépendance change
pnpm mobile         # démarre Expo
pnpm typecheck      # vérifie les types
```

## État

Lot 1 : écrans et parcours de leçon, données locales, connexion simulée.
À venir : Clerk, API et base Neon (lot 2), révision espacée et notifications (lot 3).
